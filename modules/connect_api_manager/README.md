# Connect|API Manage 1.1.2

Módulo administrativo do Connect|API.

Principais recursos:
- URL e token administrativo;
- namespace imutável `conn-<hash>`;
- criação de instâncias com prefixo automático;
- escopo configurável entre instâncias do módulo e todas as instâncias da API;
- QR Code e código de pareamento;
- estado, reinício, desconexão e exclusão;
- envio de teste;
- armazenamento criptografado dos tokens;
- exibição e cópia de token sob permissão de credenciais;
- integração opcional com o Conector.

O histórico completo de migrations permanece no subdiretório `migrations`.
