# ARGWS CRM 4.0.1

- Regras recorrentes independentes, com schema aditivo na migration 395.
- Versão do produto, banco, imagens GHCR e pacotes usam o mesmo identificador
  nativo: 401 = 4.0.1.
- Transição única a partir de 3.11.1/394: 395 mantém a DDL de recorrências;
  396–401 são marcadores NOOP. Nenhuma migration histórica é reescrita.
- Toda próxima release, inclusive apenas módulos, documentação ou CI, precisa
  avançar o núcleo em um ID. O gate valida o diff da PR sem reparar arquivos.
- O executor confirma a versão realmente gravada no banco antes de anunciar
  sucesso e recusa reduzir um banco que esteja à frente do código.
- Tags históricas são preservadas. A base incremental é escolhida pelo ID nativo
  e por evidências de origem; o pipeline não calcula versão pelo título da PR.

Antes de atualizar, faça backup de arquivos, banco e uploads. Aplique o pacote
ou imagem versionada e conclua a atualização nativa do banco como administrador.
Não há habilitação adicional de recursos financeiros nesta release.
