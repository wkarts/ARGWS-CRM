# ARGWS CRM v3.5.0

## Destaques

- Deployer desktop com interface gráfica para preparar compose.yaml e .env em Windows x64 e Linux x64.
- CLI do deployer mantida para automação e servidores sem desktop.
- A GUI e a CLI geram a partir dos mesmos modelos, preservam .env existente e validam a stack.
- Pacotes PHP, ZIP de implantação, binários, checksums e manifesto ficam anexados a esta mesma release.
- O canal develop usa uma única prerelease contínua, atualizada na tag argws-crm-develop.

## Migrations

A versão 3.5.0 configura o nível de migration 350. Para que o migrador sequencial do CodeIgniter percorra o caminho completo, esta release inclui os marcadores sem DDL 343, 344, 345, 346, 347, 348 e 349, além do marcador 350. Todos têm `up()` e `down()` vazios porque esta entrega não altera o schema. Instalações existentes avançam pelo caminho 342 → 343 → … → 350. O arquivo 342 e os níveis anteriores permanecem intactos; o validador falha se faltar qualquer nível.

Faça backup do banco, da configuração local e dos uploads antes de atualizar. Use o ZIP incremental sobre os arquivos existentes e aplique a migration 350 pelo fluxo normal do painel. Para instalações novas, use o pacote completo ou o provisionador da distribuição Docker.
