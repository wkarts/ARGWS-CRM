# ARGWS CRM 3.4.2

Primeira release SemVer do ARGWS CRM.

## Destaques

- Identidade ARGWS aplicada à plataforma, com módulos apresentados como recursos nativos.
- Português do Brasil como idioma padrão e único disponível, com política interna de terminologia.
- Configuração do widget de suporte no painel, independente de variáveis HUB_BASE_URL e HUB_TOKEN.
- Remoção da telemetria de usuários e licenciamento, mantendo registros locais de operação e segurança.
- Distribuição em PHP tradicional e imagem genérica FrankenPHP no GHCR.
- Pacote completo, pacote incremental e checksums SHA-256 disponíveis nesta release.
- Stacks de deploy separadas para develop e produção, com volumes persistentes e MySQL/MariaDB espelhados no GHCR.
- Deployer CLI Rust independente para gerar e validar compose.yaml e .env; o kit deploy/ fica fora dos ZIPs da aplicação.
- Imagem-base FrankenPHP publicada como package separado; tags base e dependências existentes não são atualizadas automaticamente.

## Atualização

Faça backup do banco de dados, da configuração local e dos uploads. Para uma instalação existente, aplique o ZIP incremental, preserve os dados da instalação e execute as migrations indicadas no painel. O ZIP incremental da primeira release inclui as alterações desde a base legado registrada em `.github/first-release-base.txt`; versões posteriores comparam com a tag estável anterior. O ZIP completo atende instalações novas.

A versão do produto segue SemVer. O nível de migration do banco representa o schema e só muda quando uma migration correspondente é criada.
